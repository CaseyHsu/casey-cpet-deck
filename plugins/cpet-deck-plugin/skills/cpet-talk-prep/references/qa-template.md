# Q&A 準備範本

## 來源

1. 投稿時的審稿意見（同一篇或相關期刊的意見都算）：每條意見改寫成一個「現場可能怎麼問」的問題。
2. 投影片上的每一個數字與主張：問自己「這個數字是命令值還是實測值？」「這個主張的數據撐得住嗎？」
3. 試講時聽眾（指導教授、同學）的提問。

## 每題的欄位

| 欄位 | 說明 |
|---|---|
| 編號 | Q1、Q2…；同一題的追問用 Q1a、Q1b |
| 分組 | 方法、比較公平性、數據、限制、實作、其他 |
| 可能的問法 | 1–3 種英文問法（給聽力練習用） |
| 30 秒口答 | 完整回答，先結論再理由 |
| 好唸短答 | 2–3 句、每句 ≤15 字，放進 talk.json；`**…**` 標重音 |
| 補充數據 | 只在追問時才講的數字，註明來源檔與性質（命令值／實測值） |
| 禁語 | 不能說的話（例如 prove、guarantee、global optimum、identical conditions），以及原因 |
| 對應頁 | 要翻到的備用頁或正文頁（B1…）；沒有備用頁就放 `other` |

## 放進 talk.json

- 有備用頁的題目放 `backup`（頁碼＝備用頁在簡報中的序號），`hint` 寫「被問到什麼時翻這頁」與禁語。
- 沒有備用頁的放 `other`，`note` 寫補充數據與禁語。
- 應對句放 `phrases`：聽不清楚、確認意思、爭取時間、限制類問題、答不出來。

## 原則

- 先講一句結論，再給一個數字，就停。
- 限制類問題直接承認（"Yes, this is a limit."），接著說可行的下一步。
- 主張以數據撐得住的範圍為限；兩筆數據方向相反時不主張。
- 被直接追問數值時，只說「設定值」相同，不說「量到的值」相同（除非真的相同）。
