# 舊簡報 → 新模板轉換 SOP（legacy conversion）

> 適用情境：使用者提供一份舊模板時期的 .pptx，要求「更新成實驗室新模板／CPET 風格版本」。
> 本 SOP 由兩個實際轉換案例提煉（2025戰鬥營進度回報 9→10 頁、Final Project Report 49→55 頁，2026-07）。
> 核心原則：**內容忠實轉錄、公式重新渲染、風格依 lab-style-conventions.md 重排、不可考處如實標註。**

## 步驟 L1：機械抽取（跑腳本，不要手寫）

```bash
python scripts/extract_legacy.py 舊簡報.pptx workdir/
```

產出 `extract_report.md`（逐頁文字／表格／圖片＋旗標）、`media/`（全部圖片）、`pages/`（旗標頁 150dpi 渲染圖）。旗標處理規則：

| 旗標 | 意義 | 處理 |
|---|---|---|
| HIDDEN | 原稿隱藏頁 | **預設排除**（尊重原稿設定）；於交付說明中告知使用者 |
| OMML | 含 Office 數學物件 | 讀 `pages/` 渲染圖，**逐條視讀轉錄為 LaTeX** 進 equation 頁——禁止截圖貼上 |
| GROUP | 群組物件（實照疊標註、多圖拼貼） | 採**內容區裁切**：從渲染圖裁下內容區當單一圖片（見 L3） |
| SPARSE | 文字稀疏無圖 | 整頁必須視讀，內容多半是 OMML 或 OLE |
| EMPTY_TABLE | 表格殼無內容 | 視讀渲染圖補值——常是浮動文字框拼出的假表格 |

## 步驟 L2：情境判定（步驟 0.5，通常可全部從原稿判出）

- 原稿有「第X章／圖 X.Y／小節編號徽章」→ **書面報告配套**（章節式編號＋subtitle 帶小節編號）；只有流水圖號或無編號 → 獨立簡報（流水號）。
- 有 Gantt／weekly 字樣 → 講義/weekly 型；有緒論+結論章 → 成果報告型。
- 原稿缺骨架硬規則要求的章節（如成果報告缺 Summary 章）→ **依規範補建**，內容由全稿歸納（動詞開頭目標句），並在交付說明中標明「新增頁」。

## 步驟 L3：內容重建規則

1. **公式**：一律轉錄 LaTeX 重新渲染（equation／two_col），每條補 `note` 物理意義（原稿沒寫的，依技術內容撰寫）；設計計算頁保留數值代入鏈；一頁超過 3 塊即拆頁（KCL 三節點 → p/n＋o 兩頁的先例）。
2. **拼貼／疊標註頁**：`pdftoppm -r 150` 渲染 → `convert -crop` 裁內容區。裁切原則：去掉舊模板的標題列、頁框、頁碼；保留內容自身的標籤與 caption；裁完必目視檢查一次（第一輪裁切殘留文字列是常態）。
3. **表格**：重建為 `table` 類型吃新樣式；**儲存格模糊不可辨者標「（原稿不清晰，待補）」，禁止杜撰數值**。
4. **修字**：明顯錯字順手修正（「以寄給」→「已寄給」），技術數值一律不動。
5. **出處**：原稿含 URL／廠商來源 → 移入 caption「（資料來源：…）」；模擬檔名標註（.psimsch/.m）保留進 caption。
6. **WMF/EMF 向量圖**：優先用裁切法取代（LibreOffice 轉檔品質不穩）。
7. **影片/OLE**：以截圖＋「原簡報以嵌入連結播放」註記代替。

## 步驟 L4：建構與 QA

照主 Workflow 步驟 2–4（plan.json → build → 三層 QA）。轉換案特別注意：
- 舊稿 4:3 圖在 16:9 版面的比例——建構器等比縮放會自動處理，但單圖過高時考慮 2 張並排重組。
- 交付說明必列：頁數對照（原 N 頁 → 新 M 頁及增減原因）、排除的隱藏頁、標「待補」的欄位清單、新增頁清單。
