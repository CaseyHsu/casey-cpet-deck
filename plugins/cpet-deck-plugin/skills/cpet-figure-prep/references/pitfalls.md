# cpet-figure-prep：靜默失敗清單

> 本檔記錄的每一項都是**實測確認**、且**不會拋出任何錯誤訊息**的失敗模式。
> 共同特徵：程式正常結束、檔案也產得出來、看起來沒事，但結果是錯的。
> 動手改 `figprep.py` 前先讀這份，可省下重複排查。

---

## 1. `Image.fromarray()` 建立的影像，`ImageDraw.floodfill()` 寫入會被靜默丟棄

**這是本工具開發過程中實際踩到的，也是最陰險的一個。**

```python
mask = Image.fromarray(m, "L")          # m 是 numpy uint8 陣列
ImageDraw.floodfill(mask, (0, 0), 128, thresh=0)
np.array(mask)                          # 完全沒變
```

實測結果：`floodfill` 在 **0 ms** 內返回、不拋例外、遮罩值分布與呼叫前完全相同。
下游算出「去背比例 0%」，於是輸出一張「處理過但其實沒動」的圖——而且因為原圖本來就
是白底，肉眼看不出差別。

**原因**：`Image.fromarray` 建立的影像與 numpy 緩衝區共享記憶體，PIL 的像素寫入路徑
在這種情況下不生效。

**正確做法**：用 `Image.frombytes("L", size, arr.tobytes())` 或
`Image.fromarray(...).copy()` 強制取得獨立緩衝區。實測後者 139 ms、前者 131 ms，
都正確填充。

**回歸測試**：對一張已知有大面積白底的圖跑 `debg`，斷言去背比例 >50%。
比例為 0 就是這個 bug 復發。

## 2. 全域「白轉透明」會把圖示內部挖空

外部生圖工具的輸出常見「近白底＋圖示內部也有白」的結構：放大鏡的鏡片、機器人的眼白、
流程圖方塊的填色。若用 `alpha = 0 where pixel is white` 這種全域規則，內部白會一起
變透明，圖被挖爛——而且**不會報錯**，只有目視才看得出來。

**正確做法**：只去除「從影像邊界連通進來」的近白像素。實作上先把遮罩外圈補一圈白，
再從 (0,0) 做 flood-fill，只有連通到邊界的白區會被標記。

**回歸測試**：素材圖刻意做成「白底＋藍圓＋圓內白色鏤空」。去背後斷言
圓內中心點仍為 `(255,255,255,255)`（不透明白）、四角為 `alpha=0`。

## 3. 去背門檻設錯會清空整張圖，且不報錯

`--threshold` 太低時，圖本身的淺色區塊會被判為「近白」，flood-fill 一路吃穿整張圖。
輸出是一張幾乎全透明的 PNG，放進簡報就是一片空白。

**處置**：`debg` 內建守門——去背比例 >97% 直接中止並提示調高 threshold；
<1% 印警告（多半是圖有外框，邊界不是白色，這張其實沒被改到）。

## 4. 中文 OCR 在 Cowork 沙箱不可用

`tesseract` 本體有裝，但只有 `eng` 與 `osd` 兩個語言包；`chi_tra` 需要
`apt-get install`，而 Cowork 沙箱沒有 root，會直接被拒：

```
E: Could not open lock file /var/lib/dpkg/lock-frontend - (13: Permission denied)
```

**若不處理**，以中文字串定位會得到「找不到文字」的誤導訊息，讓人以為是圖片問題。

**處置**：`locate_text()` 偵測到查詢字串含中文且 `chi_tra` 不在語言清單時，直接拋出
明確訊息，同時給出兩條出路（本機安裝語言包／改用 region 路徑）。

**實測基準**：英文介面截圖的 OCR 品質很好——Casey 的實際截圖上
`Create a project`、`What are you working on?` 的辨識信心值 92–96，bounding box 精準。
所以英文 UI 走 OCR 是可靠的，只有中文需要改道。

## 5. 標籤蓋到截圖既有文字，要到嵌入簡報後才發現

手工標註時標籤位置憑肉眼放，單張全尺寸看起來還好，但圖放進 `two_col` 或
`figure` band 縮放後，標籤與截圖原有文字擠在一起就看不清了。實測是**紅框座標平均要修
2 次、標籤重疊要到 pptx 建置完成才被發現**，來回成本很高。

**處置**：
- 標籤位置由工具在框的四周（右／下／上／左／右下／右上）計算**局部墨水密度**後挑最空
  的一處，用積分圖做 O(1) 查詢；同時排除超出畫布、以及與先前標籤重疊的候選。
- 執行記錄印出每個標籤放在哪一側與該處密度，方便判斷。
- 若四周都放不下會退回「框內」並在記錄中明確標示——看到這個就要調整框。
- `annotate` **強制產生預覽拼接圖**，並在輸出訊息提醒先看過再放進簡報。

## 6. 預設點陣字型畫不出中文標籤

`ImageFont.load_default()` 是點陣字型，中文會變成方框，而且**不會報錯**。

**處置**：`_font()` 依序尋找 Noto Sans CJK 等字型，全部找不到時印警告到 stderr
（而非靜默降級）。沙箱實測 `/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc` 可用。
