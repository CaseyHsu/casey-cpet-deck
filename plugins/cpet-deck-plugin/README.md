# cpet-deck-plugin

CPET / YS Lai Lab 實驗室簡報生成產線，六技能：

- 建置前：`cpet-input-template`（轉譯＋數據查核表）→ `cpet-yslai-pptx`（組裝，含大會官方模板 profile）／
  `cpet-infographic-forge`（新繪示意圖）／`cpet-figure-prep`（既有圖與 MATLAB .fig 重繪）
- 定稿後：`cpet-deck-finalize`（防覆寫、快照、動畫、衍生版本）、`cpet-talk-prep`（講稿、講稿版、文字稿、Q&A）

安裝、使用與授權說明見 repo 根目錄 [README.md](../../README.md)。本檔僅為 plugin 目錄層級的簡短索引。
